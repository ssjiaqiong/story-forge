# StoryForge 文档

本目录是工程文档的唯一存放位置，随代码一起版本管理。文档内容以**当前代码实现**为准：不描述未实现的功能，不保留已废弃的条目。

| 文档 | 内容 | 主要读者 |
|---|---|---|
| [01-需求规格说明书](./01-需求规格说明书.md) | 角色与权限、业务规则、功能需求（按模块 + 编号）、非功能需求、数据概览、验收标准 | 产品、测试、开发 |
| [02-详细设计说明书](./02-详细设计说明书.md) | 架构、包结构、通用能力、数据隔离、认证、AI 与提示词体系、业务模块、关键流程、前端、数据模型、接口规约、多库、部署 | 开发、维护 |
| [03-数据库兼容与部署运维](./03-数据库兼容与部署运维.md) | 三库兼容、数据目录、容器/远程/TCR/Nginx/桌面版部署、备份恢复与故障处理 | 运维、部署 |

## 阅读顺序

1. 新成员了解产品：01 §2~§5
2. 接手开发：02 §2~§4，再按模块查 §3.9
3. 部署上线：03 §7~§8
4. 排障：03 §8.5 + 02 §9

## 文档约定

- **代码是唯一事实来源**。文档与代码冲突时以代码为准，并应尽快修正文档。
- 功能变更时同步更新：新增功能 → 01 加 FR 条目 + 02 加模块/流程；未实现的内容**不写入**。
- 编号稳定：`FR-xxx-nn` 一旦分配不改变含义；删除功能时一并删除条目，不留占位。
- 表结构以 `src/main/resources/db/migration/postgresql/` 为准；接口以 `/v3/api-docs` 与 `app/README.md` §6 为准。
- 文档中出现的示例域名、IP、密钥均为占位值；真实配置只放在 `script/deploy/server.env`（不入库）。
